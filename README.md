1) null vs undefined

undefined mane variable declare kora hoise kintu kono value assign kora hoy nai, eta JavaScript nijer theke set kore.
null mane intentionally empty value assign kora hoise, eta developer nijer hate set kore.

2) map() vs forEach()

map() protita element niye kaj kore ebong ekta notun array return kore.
forEach() sudhu loop chalai, kintu kono notun array return kore na.

3) == vs ===

== sudhu value compare kore ebong proyojon hole type convert kore.
=== value o type duita-i compare kore ebong type convert kore na.

4) async/await er importance

async/await asynchronous kaj ke sohoje readable kore ebong Promise handle kora easy kore.
Eta .then() chain avoid kore ebong try...catch diye error handle kora sohoj hoy.

5) Scope (Global, Function, Block)

Scope bole dei kon jayga theke kon variable access kora jabe.
Global puro program jure kaj kore, Function sudhu function er vitore, ar Block {} er vitore limit thake.
